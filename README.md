# AeroMint V2 Mini App
Mobile-first Telegram Mini App starter with Home, Tasks, Invite, Rank and Profile tabs.
Backend: https://aeromint-v2-backend-production.up.railway.app
Run: npm install && npm run dev
Build: npm run build

Production rewards must remain server-side and require Telegram initData validation, real task verification, anti-fraud controls and transactional reward accounting.
